## 한계와 남은 범위

이26개는 합성 응답에 대한 UI 검증입니다. 실제 브라우저→Spring→FastAPI→DB/원장 결합, 실제 원천/모델 정확도, 저장 리포트와 계산 응답/PDF의 일치, 수학 전 범위·극단값·입력 검증·해외시장/환율·접근성은 남습니다. 상관행렬 자체의 화면은 이 단계에서 검증하지 않았습니다. 기존 PDF 스타일 실패는 유지하며 이 단계에서 PDF를 재생성하지 않습니다. 제품 결함은 수정하지 않았고 전체 QA 완료 판정이 아닙니다.
